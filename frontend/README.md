# Lynjax Frontend

Frontend previsto para Lynjax beta 0.5 usando React y Vite.

## Objetivo

Mostrar una demo clara del flujo Lynjax: estado del assessment, targets, checks, evidencia y reportes.

## Stack previsto

- Node.js LTS
- React
- Vite
- TypeScript
- Testing/lint básico a definir al crear el proyecto

## Comandos previstos

```bash
npm install
npm run dev
npm run build
npm test
```

## Primera meta técnica

Crear una pantalla inicial con la propuesta de valor de Lynjax y un dashboard mockeado antes de conectar datos reales.
