# Lynjax — Kit mínimo de marca

Este directorio contiene la base inicial del sistema de marca Lynjax para documentar decisiones antes de producir artes finales.

## Restricción actual

No se incluyen imágenes generadas ni análisis de imágenes. Los archivos aquí son guías, especificaciones, copy y plantillas editables.

## Contenido

- `00-foundation/`: fundamentos de marca, posicionamiento y voz.
- `01-logo-system/`: requisitos del futuro sistema de logo, sin generar arte todavía.
- `02-color/`: paleta base y tokens iniciales.
- `03-typography/`: dirección tipográfica inicial.
- `04-messaging/`: mensajes, tagline y descripciones.
- `05-applications/`: especificaciones para landing, dashboard y reporte.
- `06-assets/`: carpetas vacías para fuentes y exportaciones futuras.
