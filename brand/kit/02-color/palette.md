# Lynjax — Paleta inicial

## Colores principales

- Deep Navy: `#083B5C`
- Signal Blue: `#0E7490`
- Trace Teal: `#2DD4BF`

## Neutrales y soporte

- Ice Background: `#F2FAF8`
- Slate Text: `#0F172A`
- Muted Line: `#B7CDD1`

## Uso recomendado

- Deep Navy: encabezados, navegación, fondos oscuros, autoridad visual.
- Signal Blue: acciones principales, enlaces, acentos de producto.
- Trace Teal: estados activos, highlights, conexiones, métricas positivas.
- Ice Background: fondos de landing/reportes.
- Slate Text: texto principal.
- Muted Line: bordes, divisores, conectores secundarios.
