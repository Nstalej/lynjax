# Lynjax — Requisitos del sistema de logo

> No generar imágenes todavía. Este archivo define criterios para la futura producción.

## Versiones necesarias

1. Logo horizontal: isotipo + wordmark.
2. Logo vertical: isotipo arriba + wordmark.
3. Isotipo solo.
4. Versión monocromo.
5. Versión para dark mode.
6. Favicon/app icon.

## Dirección conceptual

- Explorar una `L` o `X` formada por nodos/conexiones.
- Evitar una red genérica sin personalidad.
- Mantener alta legibilidad de `LYNJAX`.
- Debe funcionar en tamaños pequeños.

## Reglas preliminares

- No usar detalles que desaparezcan en favicon.
- No depender únicamente de gradientes.
- Preparar versión plana/vectorial cuando se diseñe.
- Validar contraste sobre fondo claro y oscuro.
