# Lynjax — Dashboard demo visual spec

## Objetivo

Definir una dirección visual para un dashboard demo sin crear imágenes todavía.

## Componentes mínimos

- Header con nombre Lynjax y estado del assessment.
- Cards de resumen: devices, checks, findings, evidence items.
- Panel de scope autorizado.
- Lista de dispositivos evaluados.
- Timeline de evidencia o hallazgos.
- Botón para generar reporte.

## Estilo

- Fondo claro `#F2FAF8`.
- Texto principal `#0F172A`.
- Acentos `#0E7490` y `#2DD4BF`.
- Bordes sutiles `#B7CDD1`.
