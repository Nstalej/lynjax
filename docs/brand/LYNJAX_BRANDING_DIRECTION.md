# Lynjax — Branding Direction

## Nombre

**Lynjax** queda como candidato fuerte para el rebrand de NetVault.

Razones:

- Corto y memorable.
- Suena tecnológico sin ser demasiado genérico.
- Evoca indirectamente conexión, link, red y nodos.
- Funciona bien como marca de producto y como nombre de módulos.
- No tiene la carga negativa de nombres tipo `nul/null`.

## Tagline evaluado

Propuesta corregida:

```text
Lynjax — Intelligent Network Audit & Traceability
```

Correcciones necesarias desde la frase escrita originalmente:

- `Inteligent` → `Intelligent`
- `Netwok` → `Network`
- `tracebility` → `Traceability`

## Opinión sobre el tagline

La idea es buena porque comunica exactamente el territorio del producto:

- auditoría de red;
- trazabilidad;
- inteligencia/asistencia automatizada;
- enfoque técnico.

Sin embargo, como tagline comercial principal puede sentirse algo largo y rígido.

## Variantes recomendadas

### Opción principal recomendada

```text
Intelligent Network Audit & Traceability
```

Buena para documentación, landing formal y presentación institucional.

### Opción más limpia para logo

```text
Network Audit & Traceability
```

Más corta, más legible debajo del logo.

### Opción más comercial

```text
Network Visibility, Audit & Traceability
```

Mejor si se quiere comunicar valor, no solo función.

### Opción más fuerte para SaaS/producto

```text
See. Audit. Trace.
```

Muy usable en landing, hero y campañas.

### Opción técnica moderna

```text
Intelligent Network Visibility
```

Más simple y más flexible si el producto crece más allá de auditoría.

## Recomendación final de uso

Usar dos niveles:

```text
Logo/tagline corto:
Lynjax — Intelligent Network Visibility

Descripción extendida:
Intelligent network audit, assessment and traceability for real infrastructure.
```

O si se quiere mantener la idea original:

```text
Lynjax
Intelligent Network Audit & Traceability
```

## Análisis visual de la imagen de referencia

### Fortalezas

- El símbolo de nodos comunica red de inmediato.
- El gradiente azul/teal funciona bien para tecnología, redes y confianza.
- El fondo claro con patrones hexagonales da sensación técnica.
- La composición general ya se siente como marca de software B2B.
- El wordmark con detalles tipo circuito conecta con networking.

### Debilidades

- El símbolo de nodos es funcional pero algo genérico; muchas marcas de networking usan estructuras parecidas.
- La tipografía custom puede sacrificar legibilidad, especialmente en la `J` y la `X`.
- El fondo con hexágonos puede sentirse stock si se usa demasiado.
- El tagline debajo del logo es pequeño; en tamaños reducidos se perderá.
- El logo necesita una versión plana/vectorial para uso real: favicon, dashboard, CLI, PDF, dark mode y documentación.

## Dirección visual recomendada

### Mantener

- Azul profundo + teal/cyan.
- Nodos/conexiones como concepto central.
- Sensación limpia, técnica y profesional.
- Fondo claro para landing institucional.

### Mejorar

- Crear un isotipo más propio: una `L` o `X` formada por nodos, no solo una red genérica.
- Simplificar el wordmark para que `LYNJAX` se lea de inmediato.
- Hacer versiones:
  - horizontal;
  - vertical;
  - solo icono;
  - monocromo;
  - dark mode;
  - favicon.
