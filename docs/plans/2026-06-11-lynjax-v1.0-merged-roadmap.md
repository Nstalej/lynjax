## Version Boundary for This Sprint

For this user-approved sprint, Day 5 target is **v1.0 test candidate**.

Interpretation of `v1.0` here:

- It must be runnable for base tests in a local/sandboxed/virtual lab.
- It can remain a controlled test candidate, not a production network scanner.
- It must not imply production readiness for real client networks, SNMP, SSH, AD collection, or LLM actions.
- It should be taggable as `v1.0-rc1` unless Alejandro explicitly approves final `v1.0` publication after validation.

## Safety Boundaries

Hard limits for all cron jobs:

- Do not install Docker Desktop, WSL distributions, Hyper-V, VirtualBox, Containerlab, GNS3, EVE-NG, winget packages, drivers, or Windows features without explicit current-turn approval.
- Do not use real credentials.
- Do not scan external networks.
- Bind demo services to localhost / lab-only networks.
- Keep Containerlab topology sanitized and documentation-first if runtime is unavailable.
- If runtime tools are missing, prepare scripts/docs and report exact missing prerequisites instead of pretending tests ran.
