# Lynjax v1.0-rc1 Release Notes

Fecha: 2026-06-15
Tipo: Release candidate técnico para pruebas de Alejandro
Tag previsto: `v1.0-rc1`

## Estado

`v1.0-rc1` es un candidato de prueba, no una publicación final v1.0. Está orientado a validar que Lynjax puede ejecutarse localmente y en un entorno WSL2/Ubuntu + Docker Compose con pruebas base.

## Cambios principales

- Shell de plataforma Lynjax con navegación modular, topbar y sidebar colapsable.
- Sistema bilingüe ES/EN persistente.
- Módulos preparados para Activos, Conectividad, Assessments, Evidencia, Reportes, Topología, Directorio/AD e Inteligencia/LLM.
- Flujo seguro frontend → backend para assessment demo.
- Respuesta backend estructurada con evidencia, risk level, safety notice y reporte Markdown.
- Documentación de preparación Containerlab y Docker Compose para WSL2/Ubuntu/VM/CI.
- Scripts reforzados para `python`/`python3` y ejecución WSL/Linux.
- `.gitattributes` para normalizar LF en scripts/código/docs y evitar fallos CRLF en WSL.
- Manuales actualizados y manual PDF/LaTeX de v1.0-rc1 cuando el toolchain local lo permite.

## Validación

Pasó:

- Backend pytest: 5 tests.
- Frontend build Vite.
- Sintaxis bash.
- Lab static validation.
- Dev start + smoke local + dev stop en Windows/Git Bash.
- WSL2 Ubuntu: pytest, frontend build, lab validation, Docker Compose config y stack app+lab con health/HTTP smoke.

Advertencias:

- `npm audit --audit-level=high` reporta 2 high por `esbuild` vía Vite. No se aplicó `npm audit fix --force` porque propone upgrade mayor a Vite 8.
- `containerlab` no está instalado en WSL2; la topología queda validada de forma estática.

```bash
npm --prefix frontend run build

bash scripts/dev-stop.sh
```
