# Lynjax Brand Brief

## Core identity

**Name:** Lynjax  
**Primary tagline:** Intelligent Network Visibility  
**Extended line:** Intelligent network audit, assessment and traceability for real infrastructure.

## Positioning

Lynjax is a technical network assessment product for people who need visibility, evidence and traceability without deploying a heavy enterprise monitoring stack first.

It sits between a manual network audit and a full monitoring platform:

- more structured than ad-hoc scripts;
- lighter than enterprise monitoring;
- focused on authorized assessments;
- report-first and evidence-first;
- local-first for beta 0.5.

## Brand personality

- Technical, not flashy.
- Precise, not generic.
- Trustworthy, not scary.
- Modern, but readable.
- Intelligent, but human-controlled.

## Messaging hierarchy

### Short logo lockup

```text
Lynjax
Intelligent Network Visibility
```

### Hero headline options

1. See your network with audit-grade clarity.
2. Intelligent visibility for real network assessments.
3. Trace devices, evidence and risks from one local assessment workspace.

### Supporting copy

Lynjax helps technical teams run authorized network assessments, capture traceable evidence and generate clear reports without starting from a heavy monitoring deployment.

## What Lynjax should communicate visually

- Nodes and links.
- Trace paths.
- Verified checkpoints.
- Audit evidence.
- Network visibility.
- Calm technical confidence.

## What to avoid

- Generic blockchain-style node clouds.
- Overly dark hacker/security aesthetics.
- Purple-blue AI gradient clichés.
- Fake metrics and dashboard slop.
- Too many glowing effects.
- Taglines that overpromise autonomous security.

## Product module names

- Lynjax Core
- Lynjax Assessment
- Lynjax Reports
- Lynjax Lab
- Lynjax Agent

## Logo direction

The icon should combine an `L` or `X` structure with connected nodes. The mark must work as:

- full-color horizontal lockup;
- square app icon;
- favicon;
- monochrome mark;
- dark-mode mark;
- report header.

## Reference interpretation

The supplied reference image has the right direction: teal/blue technical palette, node network icon and light technical background. The final identity should be cleaner, less generic and more vector-friendly.
